## 상태

🚧 SwiftUI로 스플래시 화면, 로그인/회원가입 흐름(`SignUps/`), 공용 색상 확장(`ColorExtension.swift`)까지 구현한 초기 단계입니다.

## 구조

```
Streak/
├─ StreakApp.swift        앱 진입점
├─ SplashView.swift       스플래시 화면
├─ ContentView.swift      로그인 이후 메인
├─ SignUps/               회원가입 · 로그인 화면
└─ ColorExtension.swift   HEX 색상 확장
```

## 실행

Xcode에서 `Streak.xcodeproj`를 열고 실행합니다.
